### 1. The Agent Loop Has More Power Than You Know — But It's Disconnected From The God Factory

The `EnhancedAgentLoop` is significantly more capable than what's wired into The God Factory. It has:

This means you can right now drop a spec file into your project, reference its path in the God Factory prompt, and the agent reads it. **The God Factory UI has no way to surface this feature to you.**

- **Exploration Gate** — on the first iteration in an existing codebase, the agent is forced to read the entire codebase structure and produce an architecture summary BEFORE it writes any code. This prevents it from building disconnected redundant files. **Critical guard rail. Currently only wired into the Project Factory / regular agent loop, NOT God Factory's auto_intel loop.** The God Factory agent runs without the exploration gate, meaning it could write blindly.

- **Tool Policy Gate** — every tool call (web_search, write_file, spawn_agent, run_shell) goes through toolPolicyGate.ts which tracks context taint levels (user/local_file/model_output/web/peer).
