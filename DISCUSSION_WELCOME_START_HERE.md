# 👋 Welcome to Personal IDE — Start Here

Personal IDE is an agentic development environment with autonomous workflows, multi-model routing, and a living help/roadmap system inside the app.

## Quick links
- Main repo: https://github.com/Ileices/personal_IDE
- Security resolution thread: https://github.com/Ileices/personal_IDE/discussions/10
- In-repo security policy: https://github.com/Ileices/personal_IDE/blob/main/SECURITY.md
- Documentation index: https://github.com/Ileices/personal_IDE/tree/main/documentation

## If you are new
- Introduce yourself and what you are building.
- Share your stack (web/backend/local models).
- Tell us which part of Personal IDE you want to use first.

## Best ways to contribute
- Bug reports with repro steps and environment.
- Feature requests tied to real workflows.
- Discussion posts with results from experiments.
- PRs that include tests and security checks.

## How this community thread will be used
- Weekly project progress summaries.
- Security status rollups.
- Architecture decisions and roadmap deltas.
- Calls for testing specific subsystems.

Fun Fact: the in-app help registry is designed as a runtime knowledge system, so users can search architecture and operational guidance without leaving the IDE.
