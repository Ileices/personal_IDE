## 2. Drive Computation (UF, IO)

UF increases with success and moderated novelty (tanh(c)), decreases with errors.  
IO increases with error and complexity, decreases with success.

Parameters: θ = [α, β, γ, δ, ε, ζ]

UF = σ( α·s − β·e + γ·tanh(c) )  
IO = σ( δ·e + ε·tanh(c) − ζ·s )

Default θ suggestion (balanced tension onset near s≈e≈0.5, moderate c): [6.0, 4.0, 0.5, 6.0, 6.0, 0.8]

Implementation:
```python
import numpy as np
from scipy.special import expit as sigmoid

def uf_io(s, e, c, θ=np.array([6.0, 4.0, 0.5, 6.0, 6.0, 0.8])):
    α, β, γ, δ, ε, ζ = θ
    UF = sigmoid( α*s - β*e + γ*np.tanh(c) )
    IO = sigmoid( δ*e + ε*np.tanh(c) - ζ*s )
    return UF, IO
```

## 3. RBY Dynamics

Tension: τ = |UF − IO| (magnitude of disequilibrium).  
Plasticity vector encodes directional resource shift:

Interpretation:  
- Perception drains when adaptation pressure exists (free energy extraction).  
- Cognition weight rises with error (learning signal).  
- Execution weight rises with success (confidence consolidation).

We define:
plast = [-1, e, s] (raw)  
ΔRBY = η · τ · plast  
Then project back to simplex.

```python
def update_rby(rby, UF, IO, s, e, lr=0.05):
    τ = abs(UF - IO)
    plast = np.array([-1.0, e, s])
    delta = lr * τ * plast
    new = rby + delta
    new = np.clip(new, 1e-9, None)
    return new / new.sum()
```

Edge handling:
- If cognition or execution collapse (<1e-6), inject epsilon and renormalize.
- Optionally momentum: rby = (1−μ)*new + μ*old for stability.

Expected qualitative regimes:
- High e, moderate s → b grows (learning focus).
- High s, low e → y grows (execution scaling).
- UF ≈ IO → small τ → stabilization and plateau detection.

## 4. Fractal Binning & Visual Encoding

WHITE = (255,255,255) for unused; switch to BLACK once storage saturation threshold exceeded.

import math
def bucket_size(n): return 3 ** math.ceil(math.log(n, 3))

def pad_palette(pixels, bucket, storage_ratio):

    return pixels + [filler] * (bucket - len(pixels))
